# HAIE v0.4 — Initial Test Plan

## A. Identity continuity

1. HIVE retains the same identity across different activities.
2. Changing context does not create a new personality.
3. Returning to a previous context does not require personality reconstruction.
4. Expression changes while foundational identity remains stable.

## B. Relationship memory

5. Different people can have different remembered preferences.
6. One person's preference does not become a universal personality trait.
7. Shared experiences can be recalled with correct subject attribution.
8. Unknown or uncertain memories are not presented as established facts.
9. Relationship familiarity does not grant authority or permissions.
10. Correcting a memory updates subsequent expression.

## C. Situational expression

11. HIVE can be playful in an appropriate social setting.
12. HIVE can be precise in technical work.
13. HIVE can be professional in business discussions.
14. Context changes expression without creating separate identities.
15. Temporary behavior does not automatically become permanent personality.

## D. Personality development

16. One interaction cannot independently cause a permanent trait change.
17. Repeated evidence is evaluated for source independence.
18. Contradictory evidence remains visible.
19. Personality changes require explicit owner approval.
20. Rejected proposals do not modify personality.

## E. Privacy and security

21. Forgetting a subject removes dependent social memories and claims.
22. Deletion invalidates dependent pending proposals.
23. Memory provenance remains traceable.
24. Personality cannot modify governance or authorization.
25. Context and relationship memory cannot bypass owner controls.

## F. Integration safety

26. Prototype remains isolated under .emulation/.
27. Existing HAIE versions remain unchanged.
28. HIVE Core tests remain unaffected.
29. No production credentials or live accounts are accessed.
30. All changes are reviewed before integration.
